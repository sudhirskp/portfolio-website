## 🎯 About

This is my personal portfolio website featuring a **cyberpunk/hacker aesthetic** with animated Matrix rain background, terminal-style UI, and smooth interactions. Built with pure HTML, CSS, and JavaScript - no frameworks needed!

### ✨ Key Highlights

- 🎨 **Cyberpunk Theme** - Matrix rain effect, neon colors, terminal aesthetics
- ⚡ **Fast & Lightweight** - Pure vanilla JavaScript, no dependencies
- 📱 **Fully Responsive** - Looks great on all devices
- 📬 **Working Contact Form** - Direct email integration via Web3Forms
- 🎭 **Smooth Animations** - Typing effects, glitch animations, smooth scrolling
- 🌐 **SEO Optimized** - Meta tags and semantic HTML

## 🚀 Getting Started

### Prerequisites
- A modern web browser
- Basic text editor (VS Code recommended)
- Web3Forms account (free) for contact form

### Installation

1. **Clone the repository**
```bash
git clone https://github.com/sudhirskp/portfolio-website.git
cd portfolio-website/Hack-portfolio
```

2. **Open in browser**
```bash
# Simply open index.html in your browser
# Or use Live Server extension in VS Code
```

3. **Setup Contact Form** (Optional)
   - Visit [Web3Forms](https://web3forms.com/)
   - Create free account with your email
   - Get your Access Key
   - Replace `YOUR_ACCESS_KEY_HERE` in `index.html` line 213
   - See [SETUP_CONTACT_FORM.md](SETUP_CONTACT_FORM.md) for detailed instructions

## 🎨 Customization

### Change Colors
Edit CSS variables in `style.css`:
```css
:root {
    --neon-green: #00ff41;   /* Matrix green */
    --neon-cyan: #00e5ff;    /* Accent cyan */
    --neon-pink: #fa1e4e;    /* Highlight pink */
    --neon-yellow: #ffff00;  /* Warning yellow */
}
```

### Update Personal Info
1. **Name & Title**: Edit in `index.html` (Hero Section)
2. **Skills**: Modify skill cards in Skills Section
3. **Projects**: Update project cards with your own projects
4. **Social Links**: Change footer links to your profiles

### Modify Matrix Effect
Adjust in `index.js`:
```javascript
const fontSize = 10;  // Character size
const matrix = "ABCDEFGHIJKLMNOPQRSTUVWXYZ123456789@#$%^&*()";  // Characters to display
```

## 🌐 Deployment

### GitHub Pages
1. Push code to GitHub repository
2. Go to Settings → Pages
3. Select branch: `main`, folder: `/Hack-portfolio`
4. Save and wait for deployment

### Vercel
1. Import repository on [Vercel](https://vercel.com)
2. Set root directory to `Hack-portfolio`
3. Deploy

### Netlify
1. Drag and drop the `Hack-portfolio` folder to [Netlify](https://netlify.com)
2. Or connect GitHub repository
